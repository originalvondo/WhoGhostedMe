# WhoGhostedMe

## About 
This extension shows you the profiles of those people who doesn't follow a profile back on Instagram.

## Installation
- [Download](https://github.com/originalvondo/WhoGhostedMe/archive/refs/heads/main.zip) and Extract the .zip file
- Visit [Chrome extension](chrome://extensions/) / [Microsoft Edge Extension](edge://extensions/) page
- Turn on developer mode
- Click on **Load Unpacked** 
- Select the extracted zip folder that directly contains the *manifest.json* file and the extension should be installed successfully

## Usage
- Visit any profile you want to view the non-followers of
- Click on the extension from the extension bar and it will show you the non-followers within some time (It may take some time depending on the follower/following count)
